1. create a new folder
2. open it in vs code
3. create a new venv
    python -m venv venv

4. activate venv
    venv\Scripts\Activate (in powershell)
    venv\Scripts\activate.bat (in cmd)

5. create the requirements.txt
6. install packages from requirements.txt
    pip install -r requirements.txt

7. created .env file and store google api key
    GOOGLE_API_KEY = ""

8. run streamlit app
    streamlit run app.py


############################
pushing code to the github -->
0. first create empty repo on github then follow the below steps
1. git init
2. git add .
3. git commit -m "initial commit"
4. git branch -M main
5. git remote add origin https://github.com/Rajesh1505/story-generator.git
6. git push -u origin main


###########################
deployment using streamlit community cloud (github repo should be public)
1. go to link (https://streamlit.io/cloud)
2. click on
    Deploying? Try: Free-->log in with github
3. click on
    Deploy 
    then select the repo and branch and streamlit code file
    give app url name (story-generator-by-rajesh-patel)
    then go to the advanced settings and add the api key same as the .env file (GOOGLE_API_KEY = "")
    then finally click on deploy button
4. app link: https://story-generator-by-rajesh-patel.streamlit.app/
